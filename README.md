# WORDMASTER — 기억의 던전

영어 단어를 무기로 사용하는 브라우저 액션 RPG입니다. 적에게 표시된 한국어 뜻과 무기 단어가 일치하면 방어막을 파괴합니다. 일반 던전에서는 이후 어떤 무기로든 본체를 공격할 수 있습니다. 보스전에서는 방어막이 깨진 뒤에도 그 적의 단어에 맞는 무기를 사용해야 합니다.

시작 화면의 **보스전 바로 도전**으로 일반 던전을 거치지 않고 수호자와 싸울 수 있습니다. 개인 단어장에서도 **단어 저장하고 보스전 바로 도전**을 선택할 수 있습니다. 플레이어 바로 위에는 체력바와 현재 / 최대 생명력이 표시됩니다. 모든 미니언과 보스의 머리 위에는 남은 생명력에 따라 줄어드는 체력바가 표시됩니다. 다른 뜻의 방어막을 공격하면 플레이어 생명력이 8 줄어들며, 회피 중에도 오답 피해는 적용됩니다.

## 보스전

- 기본 12라운드의 단어 디펜스입니다. 개인 단어장은 단어 수만큼 라운드가 생깁니다. 현재 라운드를 화면 상단에 표시합니다.
- 보스는 오른쪽 끝, 플레이어는 왼쪽에서 시작합니다. 미니언은 오른쪽에서 순차적으로 나타나 중앙 흙길을 따라 왼쪽으로 전진합니다. 플레이어를 지나가도 접촉 피해는 없고, 뒤쪽 체크무늬 골인선을 넘으면 생명력 −12 / 점수 −50입니다. 골인한 미니언은 처치 수에 포함되지 않습니다.
- 1~3라운드 1열, 4~6라운드 2열, 7~9라운드 3열, 10라운드부터 4열로 물량이 늘어납니다. 최대 24마리가 살아 있고 빈 자리가 생기면 계속 소환합니다. 돌진과 폭탄은 사용하지 않습니다.
- 처음에는 서 있을 때 바라보는 방향으로 0.7초마다 1발이 자동 발사됩니다. 1·2·3으로 뜻에 맞는 단어를 선택하고, 적을 클릭해 특정 목표를 조준할 수 있습니다. 적을 클릭하지 않으면 마지막으로 바라본 방향을 유지합니다.
- 일반 미니언 두 마리 뒤부터 다른 단어의 **주황색 미니 보스**가 한 마리씩 섞입니다. 몸체가 더 크고 생명력이 96이며, 별표 뜻 표시와 주황색 체력바로 구분합니다. 이후 일반 미니언 약 여섯 마리마다 다시 등장할 수 있습니다. 앞뒤 160 이상의 간격을 확보하며, 미니 보스가 살아 있으면 보스 봉인이 열리지 않습니다.
- 미니 보스는 현재 무기 목록의 다른 단어를 사용합니다. 마지막 단어 묶음이 하나뿐이면 다른 단어 무기 하나를 임시로 추가해서 공격할 수 있게 합니다. 처치하면 즉시 강화 선택이 뜨며, 라운드·처치 목표·전장 상태를 유지한 채 이어집니다. 기존 3라운드마다 주어지는 강화도 유지됩니다.
- **바닥 클릭**: 앞뒤 어느 방향이든 목적지까지 이동합니다. 마우스 이동·방향키·회피 중에는 사격을 멈추며, 보스전에서 이동을 시작하면 날아가던 아군 탄환을 회수합니다. 멈춰 서면 마지막으로 바라본 방향으로 자동 발사합니다. 뒤를 보고 서 있으면 뒤로 쏩니다. 미니 보스 강화 선택 후에는 1초의 준비 시간 뒤 사격이 이어집니다.
- 다중 발사는 조준한 적과 같은 단어의 적에게만 목표를 나누며, 유도탄은 기존 목표와 같은 단어의 적에게만 다시 유도됩니다. 단어는 플레이어가 직접 선택해야 하고 실제로 다른 뜻의 적을 맞히면 오답 페널티가 적용됩니다.
- 라운드마다 3·6·9·12마리의 처치 목표를 채우면 보스 봉인이 열립니다. 이때 보스를 조준한 탄환은 같은 뜻의 미니언을 관통하므로 지속 소환에 막혀 라운드가 멈추지 않습니다. 같은 단어로 보스를 맞히면 다음 라운드로 넘어가며 이전 지원군과 탄환은 사라집니다. 마지막 봉인을 깨면 승리합니다.
- 3·6·9라운드 종료 후 **공격 속도 / 가이디드 미사일 / 발사 수 증가** 중 하나를 선택합니다. 공격 속도는 발사 간격을 줄이고, 유도탄은 목표를 추적하며, 다중 발사는 여러 미니언에게 탄환을 나눕니다. 같은 강화도 다시 선택할 수 있습니다. 유도탄은 정답 단어를 자동 선택하지 않습니다.
- 보스전에서는 방어막이 깨져도 다른 단어로 맞히면 생명력 −8 / 점수 −25입니다. 한 번의 동시 사격에는 오답 페널티가 한 번만 적용됩니다. 오답과 골인 피해는 회피 중에도 적용됩니다.
- 일시정지·힌트·강화 화면에서는 전투가 멈춥니다. 재도전하면 현재 단어장과 보스전 모드를 유지하고 공속·유도·발사 수를 초기화합니다.
- 네 방향의 장식용 구멍은 삭제했습니다. 보스 전장은 세밀한 숲길 이미지와 체크무늬 골인선으로 꾸몄습니다.

## 그래픽

- 하단 기억 슬롯은 검·활·망치의 이미지 문양과 장착 광채, 숫자키, 강화 단계가 표시되는 스킬 룬 형태입니다. 보스전에서도 기억별 원래 문양을 유지하며 공격 방식은 모두 원거리입니다.
- 단어 입력은 전투 미리보기를 갖춘 룬 제작소, 도감은 검색·숙련도·예문·해설을 보여주는 카드형 마법서입니다. 두 화면의 마법서 배경은 내장 `image_gen`으로 생성한 `public/assets/art/archive-banner.png`이며 전체 프롬프트는 `archive-generation.json`에 저장했습니다.

- 배경은 정원·달빛 서고·용암 대장간·서리 유적·보스 숲길의 이미지 5종입니다. 기존 픽셀 도형 배경을 교체했으며 일반 던전 배경은 비율을 유지해서 화면을 채웁니다. 보스 숲길은 화면 비율이 바뀌어도 모든 레인이 흙길에 놓이도록 나누어 표시합니다.
- 플레이어·일반 몬스터 3종·주황색 미니 보스·수호자, 검·활·망치는 투명 PNG 아틀라스로 표시합니다. 이미지의 프레임 경계는 왕관과 발이 잘리지 않도록 실제 그림에 맞췄습니다.
- 캔버스는 화면 크기와 기기의 픽셀 배율을 반영하며 최대 800만 픽셀로 제한합니다. 월드 좌표와 이동 속도는 유지하고, 마우스 좌표는 카메라를 통해 변환합니다. 픽셀 확대를 해제하고 부드러운 샘플링·안티앨리어싱·문자 해상도 향상을 적용했습니다. 캐릭터와 무기는 GPU에서 밉맵을 사용해 축소할 때 생기는 반짝임을 줄입니다.
- 원본은 내장 `image_gen`으로 생성했습니다. 이미지와 아틀라스는 `public/assets/art/`에 저장되어 있으며, 생성 프롬프트와 실제 이미지 크기는 `generation-manifest.json`, 캐릭터 배치 보정 프롬프트는 `character-layout-edit.txt`에서 확인할 수 있습니다.

## 조작

- 마우스 왼쪽 클릭: 바닥은 목적지까지 이동. 몬스터는 선택한 적에게 연속 공격 — 검·망치는 접근 후 공격, 활은 제자리에서 발사. 바닥 클릭·방향키·일시정지로 취소, 처치하면 종료
- Space: 일반 던전에서 가까운 적 또는 선택한 적을 조준해 공격 (누르고 있으면 연속 공격). 보스전은 정지 상태에서 바라보는 방향으로 자동 발사
- WASD / 방향키: 보조 이동. 클릭 이동과 클릭 공격을 취소
- 1 / 2 / 3: 단어 무기 선택
- Shift: 회피 (짧은 무적)
- Tab: 현재 단어의 뜻과 예문, 전투 일시정지
- Esc: 일시정지 / 창 닫기

기본 던전은 12개 단어, 일반 전투방 4개, 보스방 1개로 구성됩니다. 일반 방마다 단어당 3마리씩 등장합니다. 빈 전장에서 시작해 2초 후 첫 적이 나타나고, 위·오른쪽·아래·왼쪽에서 번갈아 등장합니다. 등장 위치는 0.8초 먼저 빛나며 등장 간격은 약 4초에서 최소 1.5초까지 줄어듭니다. 동시에 살아 있는 적은 최대 6마리입니다. 대기 중인 적까지 모두 처치해야 다음 방으로 갑니다. 보스는 모든 단어의 봉인과 그 단어의 미니언을 사용합니다.

전투 화면은 브라우저 영역 전체를 채웁니다. 생명력·회피·단어 무기·경험치·강화 상태는 화면 안의 하단 HUD에 모여 있고, 메뉴·도감·개인 단어장·보상 선택도 전장 안에서 열립니다. 전체 화면 버튼은 브라우저 전체 화면으로 전환합니다. 화면 비율이 바뀌면 전장과 이동 영역도 조절되어 여백이나 잘린 문 없이 플레이할 수 있습니다. 네 일반 방은 잔디 정원·달빛 서고·용암 대장간·서리 유적의 서로 다른 배경과 적 배치를 사용합니다. 보스방은 중앙 흙길이 있는 잔디 전장입니다. 배경의 물·용암·가구는 장식이며 별도 피해나 이동 방해를 주지 않습니다. 공격 대상은 단어 정답과 관계없이 선택되므로 플레이어가 적의 뜻에 맞는 무기를 고르는 것이 중요합니다.

‘내 단어로 던전 만들기’에서 `문제·뜻 | 답·단어 | 설명` 형식으로 3~30개를 입력할 수 있습니다. 설명은 선택입니다. 단어와 뜻은 각각 중복될 수 없습니다. 한 번에 무기 세 개씩 사용하며 마지막 세트는 1~2개여도 플레이할 수 있습니다.

## 한 판 안의 성장

- 처치한 적의 조각 3개가 자동으로 플레이어에게 날아와 각각 경험치 4를 줍니다. 레벨에 필요한 경험치는 24부터 12씩 증가합니다.
- 레벨이 오르면 전투를 멈추고 강화 3개 중 하나를 선택합니다. 방 클리어 때도 강화를 고르고 체력 10을 회복합니다.
- 모든 강화 선택은 전장을 가리지 않는 플레이어 위의 이미지 버튼으로 표시합니다. 공속·유도탄·다중 발사·검·활·망치·공격력·회피·회복에 각각 다른 문양과 색을 사용합니다. 클릭이나 1·2·3으로 선택하고 Tab으로 버튼 사이를 이동합니다. 선택 시 플레이어 주위에 강화 효과가 나타납니다. 화면 위쪽에 붙어 공간이 없을 때는 플레이어 아래로 배치하고, 크기 변경 시 위치를 다시 맞춥니다.
- 강화 버튼 원본은 내장 `image_gen`으로 생성한 투명 PNG `public/assets/art/upgrade-buttons.png`이며, 전체 생성 프롬프트는 같은 폴더의 `upgrade-buttons-generation.json`에 저장합니다.
- 강화 등장 후 0.8초 동안 선택 입력을 막아 전투 중의 클릭·키 입력이 선택으로 이어지지 않게 합니다. 이후 이미지 버튼 위에서 새로 누른 클릭 또는 1·2·3/Enter로 선택합니다. 설명·바닥·빈 공간 클릭과 공격용 Space, 계속 누르고 있는 키의 반복 입력은 강화를 선택하거나 창을 닫지 않습니다. 선택할 때까지 전투가 멈추며 자동으로 닫히지 않습니다.
- 검: 1단계 범위 증가·검기, 2단계 더 긴 검기·세 번째 공격마다 회전베기.
- 활: 1단계 부채꼴 화살 3발, 2단계 화살 5발·관통.
- 망치: 1단계 광역 충격파, 2단계 더 넓은 충격파·연쇄 폭발.
- 추가 화살·검기·충격파·관통 후의 화살은 방어막이 깨진 적만 공격합니다. 주 공격은 계속 뜻을 맞혀야 합니다.
- 무기가 모두 2단계에 이르면 공격력·공격 속도·회복 강화를 선택할 수 있습니다. 마지막 단어 묶음이 작아도 사용할 무기만 선택지에 나옵니다.
- 방어막을 정답으로 3번 연속 깨면 5초간 기억 폭주가 켜집니다. 공격 속도·본체 피해가 증가하고 검기·활 연속 사격·망치 연쇄 폭발이 활성화됩니다. 오답과 피격은 폭주 충전 횟수를 초기화합니다.
- 일시정지·힌트·강화 선택 중에는 등장·폭주·경험치 수집이 멈춥니다. 강화와 경험치는 현재 탐험 안에서 유지되고 새 탐험에서는 초기화됩니다.

## 저장 및 범위

단어별 정답·오답·힌트 횟수, 숙련도, 클리어 횟수, 최고 점수, 개인 단어장과 음소거 설정을 브라우저 localStorage에 저장합니다. 전투 중인 탐험 자체는 새로고침 시 다시 시작합니다. 브라우저 데이터 삭제 시 저장 기록도 삭제됩니다. 계정·서버·기사 자동 추출·모바일 터치 조작은 이 버전에 포함되지 않습니다.

단어 숙련도는 게임 내 반복 성공 지표이며 장기 기억을 측정하는 지표는 아닙니다. 현재 던전 정복과 단어 숙련도는 별개로 표시합니다.

Phaser 3 / TypeScript / Vite를 사용합니다. 캐릭터·배경·무기·강화 버튼은 생성한 이미지로 표시하고, 타격 순간의 짧은 정지·피격 섬광·밀쳐짐·충격파와 무기 동작은 코드로 구현합니다. 발사·피격·망치 충돌 효과음은 Web Audio로 합성합니다. 웹 폰트는 Google Fonts에서 로드하고 연결이 없으면 시스템 폰트로 대체합니다.

단위 테스트는 단어 입력 검증·의미 방어막 판정·문장 빈칸·저장을 확인합니다. 브라우저 테스트는 전체 화면 HUD·네 방향 순차 등장·등장 예고·최대 적 수·경험치와 강화·무기 진화·방어막 보호·폭주·클릭 이동·Space 공격·일시정지·개인 단어장·일반 전투와 보스의 전체 진행, 보스 자동 사격·골인 감점·유도탄 추적·강화 선택을 확인합니다. 전투 진행 테스트는 위치 고정으로 적 AI와 전투 판정을 분리하고 실제 키보드 입력으로 공격합니다.

## 기억 입력

- 모든 과목에 `문제·뜻 | 답·단어 | 설명(선택)` 한 가지 형식을 사용합니다. 예: `호기심이 많은 | curious`, `프랑스의 수도는? | 파리`, `물의 화학식은? | H2O`.
- 첫 번째 칸은 적에게, 두 번째 칸은 무기에 표시됩니다. 영어·한글·숫자·기호를 한 덱에 섞어 쓸 수 있습니다.
- 3~30개를 입력하며 문제(80자)와 답(40자)은 각각 중복되지 않아야 합니다. 선택 설명은 최대 240자이며 도감과 Tab 힌트에 표시됩니다.
- 기존에 저장한 덱은 새 입력 순서로 표시됩니다. 같은 문제·답을 다시 저장하면 기존 숙련 기록을 유지합니다.
- 도감의 숙련 점수는 정답 +18, 오답 −8, 힌트 −3을 합산해 0~100점으로 제한한 게임 지표입니다. 실제 암기율이 아닙니다.

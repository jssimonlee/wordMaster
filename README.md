# WORDMASTER — 기억의 던전

영어 단어를 무기로 사용하는 브라우저 액션 RPG입니다. 적에게 표시된 한국어 뜻과 무기 단어가 일치하면 방어막을 파괴합니다. 이후에는 어떤 무기로든 본체를 공격할 수 있습니다.

## 실행

Node.js 22 이상에서:

```powershell
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 PC 브라우저에서 엽니다.

## 조작

- 마우스 왼쪽 클릭: 목적지까지 이동. 적을 클릭하면 해당 적을 선택하고 공격 거리까지 접근
- Space: 가까운 적 또는 선택한 적을 자동 조준해 공격 (누르고 있으면 연속 공격)
- WASD / 방향키: 보조 이동. 클릭 이동을 취소
- 1 / 2 / 3: 단어 무기 선택
- Shift: 회피 (짧은 무적)
- Tab: 현재 단어의 뜻과 예문, 전투 일시정지
- Esc: 일시정지 / 창 닫기

기본 던전은 12개 단어, 일반 전투방 4개, 보스방 1개로 구성됩니다. 각 전투방을 클리어하면 회복·공격력·속도 보상 중 하나를 고릅니다. 보스는 모든 단어의 봉인을 사용하고 마지막 세 봉인은 가능한 경우 영어 예문의 빈칸을 표시합니다.

전투 화면은 화면 폭 전체를 사용하며 정보 카드는 아래에 배치됩니다. 네 일반 방은 잔디 정원·달빛 서고·용암 대장간·서리 유적의 서로 다른 배경과 적 배치를 사용합니다. 보스방은 별빛 제단입니다. 배경의 물·용암·가구는 장식이며 별도 피해나 이동 방해를 주지 않습니다. 공격 대상은 단어 정답과 관계없이 선택되므로 플레이어가 적의 뜻에 맞는 무기를 고르는 것이 중요합니다.

‘내 단어로 던전 만들기’에서 `영어 단어 | 한국어 뜻 | 영어 예문` 형식으로 3~30개를 입력할 수 있습니다. 예문은 선택입니다. 단어와 뜻은 각각 중복될 수 없습니다. 한 번에 무기 세 개씩 사용하며 마지막 세트는 1~2개여도 플레이할 수 있습니다.

## 저장 및 범위

단어별 정답·오답·힌트 횟수, 숙련도, 클리어 횟수, 최고 점수, 개인 단어장과 음소거 설정을 브라우저 localStorage에 저장합니다. 전투 중인 탐험 자체는 새로고침 시 다시 시작합니다. 브라우저 데이터 삭제 시 저장 기록도 삭제됩니다. 계정·서버·기사 자동 추출·모바일 터치 조작은 이 버전에 포함되지 않습니다.

단어 숙련도는 게임 내 반복 성공 지표이며 장기 기억을 측정하는 지표는 아닙니다. 현재 던전 정복과 단어 숙련도는 별개로 표시합니다.

Phaser 3 / TypeScript / Vite를 사용합니다. 캐릭터·배경·이펙트는 코드로 그리며 효과음은 Web Audio로 합성합니다. 웹 폰트는 Google Fonts에서 로드하고 연결이 없으면 시스템 폰트로 대체합니다.

## 검증 및 배포 빌드

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

단위 테스트는 단어 입력 검증·의미 방어막 판정·문장 빈칸·저장을 확인합니다. 브라우저 테스트는 클릭 이동·Space 공격·일시정지·개인 단어장·일반 전투와 보스의 전체 진행을 확인합니다. 전투 진행 테스트는 위치 고정으로 적 AI와 전투 판정을 분리하고 실제 키보드 입력으로 공격합니다.

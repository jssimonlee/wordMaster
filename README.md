# WORDMASTER — 기억의 던전

영어 단어를 무기로 사용하는 브라우저 액션 RPG입니다. 적에게 표시된 한국어 뜻과 무기 단어가 일치하면 방어막을 파괴합니다. 이후에는 어떤 무기로든 본체를 공격할 수 있습니다.

## 실행

Node.js 22 이상에서:

```powershell
npm install
npm run dev
```

터미널에 표시된 로컬 주소를 PC 브라우저에서 엽니다.

## 조작

- 마우스 왼쪽 클릭: 바닥은 목적지까지 이동. 몬스터는 선택한 적에게 연속 공격 — 검·망치는 접근 후 공격, 활은 제자리에서 발사. 바닥 클릭·방향키·일시정지로 취소, 처치하면 종료
- Space: 가까운 적 또는 선택한 적을 자동 조준해 공격 (누르고 있으면 연속 공격)
- WASD / 방향키: 보조 이동. 클릭 이동과 클릭 공격을 취소
- 1 / 2 / 3: 단어 무기 선택
- Shift: 회피 (짧은 무적)
- Tab: 현재 단어의 뜻과 예문, 전투 일시정지
- Esc: 일시정지 / 창 닫기

기본 던전은 12개 단어, 일반 전투방 4개, 보스방 1개로 구성됩니다. 일반 방마다 단어당 3마리씩 등장합니다. 빈 전장에서 시작해 2초 후 첫 적이 나타나고, 위·오른쪽·아래·왼쪽 문에서 번갈아 등장합니다. 문은 0.8초 먼저 빛나며 등장 간격은 약 4초에서 최소 1.5초까지 줄어듭니다. 동시에 살아 있는 적은 최대 6마리입니다. 대기 중인 적까지 모두 처치해야 다음 방으로 갑니다. 보스는 모든 단어의 봉인을 사용하고 마지막 세 봉인은 가능한 경우 영어 예문의 빈칸을 표시합니다.

전투 화면은 브라우저 영역 전체를 채웁니다. 생명력·회피·단어 무기·경험치·강화 상태는 화면 안의 하단 HUD에 모여 있고, 메뉴·도감·개인 단어장·보상 선택도 전장 안에서 열립니다. 전체 화면 버튼은 브라우저 전체 화면으로 전환합니다. 화면 비율이 바뀌면 전장과 이동 영역도 조절되어 여백이나 잘린 문 없이 플레이할 수 있습니다. 네 일반 방은 잔디 정원·달빛 서고·용암 대장간·서리 유적의 서로 다른 배경과 적 배치를 사용합니다. 보스방은 별빛 제단입니다. 배경의 물·용암·가구는 장식이며 별도 피해나 이동 방해를 주지 않습니다. 공격 대상은 단어 정답과 관계없이 선택되므로 플레이어가 적의 뜻에 맞는 무기를 고르는 것이 중요합니다.

‘내 단어로 던전 만들기’에서 `영어 단어 | 한국어 뜻 | 영어 예문` 형식으로 3~30개를 입력할 수 있습니다. 예문은 선택입니다. 단어와 뜻은 각각 중복될 수 없습니다. 한 번에 무기 세 개씩 사용하며 마지막 세트는 1~2개여도 플레이할 수 있습니다.

## 한 판 안의 성장

- 처치한 적의 조각 3개가 자동으로 플레이어에게 날아와 각각 경험치 4를 줍니다. 레벨에 필요한 경험치는 24부터 12씩 증가합니다.
- 레벨이 오르면 전투를 멈추고 강화 3개 중 하나를 선택합니다. 방 클리어 때도 강화를 고르고 체력 10을 회복합니다.
- 검: 1단계 범위 증가·검기, 2단계 더 긴 검기·세 번째 공격마다 회전베기.
- 활: 1단계 부채꼴 화살 3발, 2단계 화살 5발·관통.
- 망치: 1단계 광역 충격파, 2단계 더 넓은 충격파·연쇄 폭발.
- 추가 화살·검기·충격파·관통 후의 화살은 방어막이 깨진 적만 공격합니다. 주 공격은 계속 뜻을 맞혀야 합니다.
- 무기가 모두 2단계에 이르면 공격력·공격 속도·회복 강화를 선택할 수 있습니다. 마지막 단어 묶음이 작아도 사용할 무기만 선택지에 나옵니다.
- 방어막을 정답으로 3번 연속 깨면 5초간 기억 폭주가 켜집니다. 공격 속도·본체 피해가 증가하고 검기·활 연속 사격·망치 연쇄 폭발이 활성화됩니다. 오답과 피격은 폭주 충전 횟수를 초기화합니다.
- 일시정지·힌트·강화 선택 중에는 등장·폭주·경험치 수집이 멈춥니다. 강화와 경험치는 현재 탐험 안에서 유지되고 새 탐험에서는 초기화됩니다.

## 저장 및 범위

단어별 정답·오답·힌트 횟수, 숙련도, 클리어 횟수, 최고 점수, 개인 단어장과 음소거 설정을 브라우저 localStorage에 저장합니다. 전투 중인 탐험 자체는 새로고침 시 다시 시작합니다. 브라우저 데이터 삭제 시 저장 기록도 삭제됩니다. 계정·서버·기사 자동 추출·모바일 터치 조작은 이 버전에 포함되지 않습니다.

단어 숙련도는 게임 내 반복 성공 지표이며 장기 기억을 측정하는 지표는 아닙니다. 현재 던전 정복과 단어 숙련도는 별개로 표시합니다.

Phaser 3 / TypeScript / Vite를 사용합니다. 캐릭터·배경·이펙트는 코드로 그리며 타격 순간의 짧은 정지·피격 섬광·밀쳐짐·충격파와 무기 동작을 표시하며, 발사·피격·망치 충돌 효과음은 Web Audio로 합성합니다. 웹 폰트는 Google Fonts에서 로드하고 연결이 없으면 시스템 폰트로 대체합니다.

## 검증 및 배포 빌드

```powershell
npm test
npm run build
npx playwright install chromium
npm run test:e2e
npm run preview
```

단위 테스트는 단어 입력 검증·의미 방어막 판정·문장 빈칸·저장을 확인합니다. 브라우저 테스트는 전체 화면 HUD·네 방향 순차 등장·등장 예고·최대 적 수·경험치와 강화·무기 진화·방어막 보호·폭주·클릭 이동·Space 공격·일시정지·개인 단어장·일반 전투와 보스의 전체 진행을 확인합니다. 전투 진행 테스트는 위치 고정으로 적 AI와 전투 판정을 분리하고 실제 키보드 입력으로 공격합니다.
